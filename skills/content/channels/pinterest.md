# Pinterest

**What it is:** a visual search engine. Pins are found by keywords for months, unlike feeds
where posts die in a day. Write for search, not for followers.

**Format:** 1000×1500 (2:3) image, or 9:16 video. Bold readable title text on the image
(it's shown small on phones). Brand mark small, in a corner.

**Item body:**
```
TITLE (≤100 chars, front-load the keyword people search, e.g. "2 Days in Lisbon: Itinerary for a Weekend")
DESCRIPTION (≤500 chars; first 50 matter most; 2–3 natural keyword phrases; no hashtag lists)
ALT TEXT (what the image shows, for screen readers)
BOARD (existing board name, keyword-named)
IMAGE (file, size, text overlay wording, credit)
LINK (the exact page, with UTM)
```

**Rules**
- Every pin links to the specific page it's about, never the home page.
- Several different pins (new image + new title) per page over time are fine and normal;
  the same image re-pinned is not.
- Keyword research: type the topic into Pinterest search and use its suggested phrases; note them in `log.md`.
- Cadence: steady beats bursts (e.g. 1 a day or 3–5 a week).
- Affiliate links allowed but must be disclosed in the description; no link shorteners.
