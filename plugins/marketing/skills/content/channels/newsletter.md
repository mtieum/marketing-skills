# Newsletter

**Who gets it:** only people who opted in (UK PECR/GDPR: consent for marketing email to
individuals, a working unsubscribe in every send, the sender named). Never import contacts
from elsewhere, never add sign-ups from another purpose (e.g. account emails) without consent.

**What works:** one main thing, useful on its own, plus 2–3 short extras. Subject lines that
say what's inside. Regular day and time.

**Item body:**
```
SUBJECT (≤ 50 chars) + PREVIEW TEXT (≤ 90 chars)
MAIN: heading, 120–250 words, one link
EXTRAS: 2–3 items, one or two lines each, one link each
SIGN-OFF: a person's name
FOOTER: why they're getting it, unsubscribe, sender address (the sending tool adds these; check it does)
```

**Links:** `utm_source=newsletter&utm_medium=email&utm_campaign=<slug>`.

If the brand has no sending tool or list yet, the first item is setting one up (a decision for
the owner, flagged in the review), not a newsletter.
